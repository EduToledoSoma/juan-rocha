# Juan Rocha Boxe — projeto para Linux e Windows

**Comece em [README_DESKTOP.md](README_DESKTOP.md).**

O projeto foi atualizado a partir da versão Flutter Android/iOS e agora prepara compilações
Linux e Windows pelo Flutter e GitHub Actions. Não inclui `.exe` e binário Linux pré-compilados.

**Correções:** erro de `setState` após salvar cadastros, cartões responsivos sem avisos vermelhos
de overflow, títulos pretos em faixa dourada, valores dourados e cliques para abrir o módulo certo.

Uso de testes; os dados ficam em um banco SQLite local independente em cada computador.
